# W95FA font attribution

Designer: Alina Sava, FontsArena. Font family in the original binary: W95FA Regular, version 1.002 (Fontself Maker 3.4.0).

Primary source: https://fontsarena.com/w95fa-by-alina-sava/
Original release ZIP: https://fontsarena.com/wp-content/uploads/2020/01/W95FA.zip
Retrieved: 15 October 2026.

The source describes W95FA as a scalable, pixel-style recreation of the Windows 95 MS Sans Serif system font and explicitly releases it for personal and commercial use under the SIL Open Font License 1.1. Desk95 distributes the original WOFF2 and WOFF files unchanged, together with the original OFL.txt. Its template copyright placeholders are preserved exactly as supplied; this attribution identifies the designer from the primary release page and embedded font metadata.

Only regular weight is supplied by the author. Desk95 uses browser-synthesized bold and italic for headings, emphasized controls, and formatted document text. It does not claim a separate authentic bold font file. The application uses W95FA at a 16px minimum after visual checks found the earlier 9–13px sizes too dense; missing glyphs fall back to local system fonts. No font service is contacted at runtime.

W95FA is a licensed recreation, not the original Microsoft bitmap font. React95 R95 conversions were not bundled because that repository explicitly reserves Microsoft's bitmap-data rights despite MIT licensing its conversion tooling.
