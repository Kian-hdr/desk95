# Changelog

## 1.1.0

Initial public release of Desk95, a local workspace for documents, projects, and tasks with a Windows 95 inspired interface.

- Nested rich-text pages, linked tasks, project boards and lists, search, and command palette.
- Local ZIP backups with attachments, revisions, Recycle Bin, and save recovery.
- Offline browser support with System, Light, and Dark appearances.
- Native macOS shell with bundled assets, save-aware quit, and native file dialogs.
- Universal arm64/x86_64 build; macOS 14 or later. Runtime tested on Apple Silicon; Intel compatibility is built but not physically tested.
- Original code under MIT; third-party components and W95FA retain their licenses.
